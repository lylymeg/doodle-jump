# 🦘 Doodle Jump Light (Pygame)

Un jeu de **plateforme verticale à saut infini** inspiré du célèbere **Doodle Jump**, codé en **Python** avec **Pygame**.

---

## 📸 Fonctionnalités

- 🦘 **Saut automatique :** Le joueur rebondit tout seul dès qu'il touche une plateforme.
- 🌌 **Défilement infini :** Génération procédurale des plateformes à mesure que vous montez.
- 🔄 **Effet Wrap :** Traversez le bord gauche pour réapparaître à droite (et vice versa).
- 🏆 **Score de hauteur :** Calcul de la hauteur maximale atteinte.

---

## 🚀 Lancement

```bash
pip install pygame
python main.py
